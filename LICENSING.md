# Licensing policy

This organization uses a simple, consistent policy:

- Source code in the xfetch-cli repositories is licensed under the MIT License
  unless a repository states otherwise.
- Documentation, configuration examples, themes, logo art and brand assets are
  also MIT unless a repository states otherwise.
- Third-party dependencies keep their own licenses. The MIT license of this
  project does not relicense dependency code.
- Distributed binaries and packages must comply with every bundled
  dependency license. Preserve copyright notices and any required `NOTICE`
  files.
- Attribution to xscriptor is required when redistributing the code or
  substantially copying it.

## Repositories

The same MIT terms apply to:

`xfetch`, `api`, `plugins`, `effects`, `extensions`, `web`, `configs`,
`themes`, `logos`, `assets`, `homebrew-tap` and `.github`.

`context` is documentation and uses the MIT License as well.

## Third-party notices

When a repository needs dependency notices, add a `THIRD_PARTY_LICENSES.md` or
a `NOTICE` file and generate it with `cargo-license` or `cargo-deny`.
Do not claim that third-party code is MIT.

## Contributions

Contributions are accepted under the same MIT terms (inbound = outbound).
Contributors should certify the Developer Certificate of Origin with a
`Signed-off-by` trailer. A CLA is not required unless a separate commercial
licensing arrangement is introduced.

## Trademarks

The licenses do not grant permission to use the X or xfetch names or logos as
trademarks. See `TRADEMARKS.md`.
